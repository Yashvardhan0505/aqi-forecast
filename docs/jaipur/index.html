How it works

Every morning a GitHub Action downloads the previous day’s PM2.5 from 6 government monitors in Jaipur (CPCB data, via OpenAQ) and combines them into one value for the city. Monitors that read consistently high or low are scaled to the city average first, so a station going offline doesn’t make the city look cleaner.

A gradient-boosted tree model (scikit-learn) predicts how much PM2.5 will change from the latest day. It uses the last week of readings, the weather forecast from Open-Meteo (wind, boundary layer height, humidity, rain, temperature and pressure) and the time of year. Two more models give the 80% range. All of them are retrained on every run.

The model is scored against two simple rules: the air stays the same as the last measured day, and it is the same as the same day last week. A forecast is only useful if it beats them.

Each forecast is written to data/forecast_log.csv before its day is measured and is never edited, so the live scores are what the model actually said at the time.

Monitors used: Adarsh Nagar, Jaipur - RSPCB, Adarsh Nagar, Jaipur - RSPCB, Mansarovar Sector-12, Jaipur - RSPCB, Police Commissionerate, Jaipur - RSPCB, Police Commissionerate, Jaipur - RSPCB, RIICO Sitapura, Jaipur - RSPCB, Sector-2 Murlipura, Jaipur - RSPCB, Shastri Nagar, Jaipur - RSPCB, Shastri Nagar, Jaipur - RSPCB, VK Industrial Area Jaipur - RSPCB.
